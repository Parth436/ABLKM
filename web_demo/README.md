# Interactive visualization

Open `index.html` in a modern browser to explore the ABLKM concept.

This browser demo is a **visualization/prototype**, not the security implementation used for the paper's benchmark. In particular, its JavaScript storage/encryption logic is simplified for interaction and visualization and should not be treated as an AES-GCM/HMAC/HKDF implementation. The Python implementation under `src/` is the security-relevant prototype.
